变量与数据类型

变量通过 type() 可以获得变量类型,type 返回的类型本身是 string 型。

数据类型总览

Lua 的变量类型分成两类:

简单变量类型

复杂数据类型

核心特点

Lua 中所有的变量声明都不需要声明变量类型,它会自动判断类型。

nil(空)

没有声明过的变量不会报错,直接打印出来是 nil。

nil 就相当于别的语言里的 null。

number(数值)

number 就是所有的数值型,整数和小数都是 number。

string(字符串)

Lua 里没有 char,所以单引号、双引号都可以表示字符串。

boolean(布尔)

小结

  • type() 可以获取变量类型,返回值是 string 型。
  • 变量不需要(也不能)声明类型,赋值后自动识别。
  • 未声明的变量默认是 nil,不会报错。
  • Lua 没有 char,字符串用单双引号都可以。
