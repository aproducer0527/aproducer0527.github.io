热补丁:替换属性与索引器

热补丁不能直接写 Age = function...,属性、索引器在底层是 get_xxx / set_xxx 方法,所以要替换的是这些”方法”。

关键点

属性(Property)

属性的 getter / setter 对应的方法名:

  • get_属性名 → 替换读取(Get)逻辑
  • set_属性名 → 替换赋值(Set)逻辑

索引器(Indexer)

索引器固定方法名:

  • get_Item → 替换 obj[索引] 读取逻辑
  • set_Item → 替换 obj[索引] = 值 赋值逻辑

小结

  • 属性:get_属性名 / set_属性名。
  • 索引器:get_Item / set_Item(固定写法)。
  • get 方法返回新值,set 方法接收 (self, 值) 或 (self, 索引, 值)。
