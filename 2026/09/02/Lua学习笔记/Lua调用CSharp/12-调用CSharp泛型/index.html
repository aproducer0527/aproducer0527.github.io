Lua 调用 C#:调用 C# 泛型

Lua 对 C# 泛型方法的支持很有限,只有部分情况能用,需要专门的方法来处理。

C# 侧定义

Lua 侧使用:哪些能用哪些不能用

支持的只有:有参数 + 有 class 约束的泛型方法(TestFun1)。

小技巧:让不支持的泛型函数变得能用

用 xlua.get_generic_method 手动指定泛型类型,再调用:

三步:

  1. xlua.get_generic_method(类, "函数名") 得到泛型方法的通用引用。
  2. 通用引用(泛型类型) 指定具体类型,得到可调用的函数(这里指定 CS.System.Int32)。
  3. 调用时成员方法第一个参数传对象,再传方法参数。

使用限制

这种方式有一定的使用限制:

  • Mono 打包:这种方式支持。
  • IL2CPP 打包:
    • 泛型参数是引用类型才可以使用。
    • 泛型参数是值类型,除非 C# 那边已经调用过同类型的泛型参数,lua 中才能够被使用。

小结

  • Lua 只能直接调用有参数 + class 约束的泛型方法。
  • 无约束 / 无参数 / 接口约束的泛型方法要用 xlua.get_generic_method 手动指定类型。
  • 泛型方法第一个参数传对象本身。
  • IL2CPP 下值类型泛型有额外限制。
