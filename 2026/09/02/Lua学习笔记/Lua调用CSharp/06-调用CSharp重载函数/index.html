Lua 侧使用

遇到的问题:多精度重载

Lua 虽然支持调用 C# 重载函数,但是因为 Lua 中的数值类型只有 number 一种,所以对 C# 中多精度的重载函数支持不好,在使用时可能出现意想不到的问题:

5.2 既有 int 版本又有 float 版本,C# 侧的 Calc(int) 和 Calc(float) 都能被 Lua 的 number 匹配,可能调用到错误的那个。

解决方案:反射机制(只做了解)

XLua 提供了通过反射解决”重载含糊”的方案,但只做了解,尽量别用。

思路:

  1. typeof(类):GetMethod("方法名", {参数类型...}) 用反射拿到指定签名的那个方法。
  2. xlua.tofunction(方法) 把它转成 Lua 函数。
  3. 因为是成员方法,第一个参数传对象本身(等价于 C# 里的 this)。
  4. 一般转一次,重复使用。

小结

  • Lua 支持调用 C# 重载函数,但 Lua 只有 number,多精度重载调用可能不准。
  • 反射方案:GetMethod 指定参数类型 + xlua.tofunction 转成函数,只做了解,尽量别用。
