事件不能设空

事件(event)不像委托那样可以 = nil 清空,也不能直接加减。所以要在 C# 侧封装一层方法来给 Lua 调用,这就是上面 obj:eventAction("+", fun) 这种用法的来源——在 C# 里根据 "+" / "-" 决定 += / -=。

小结

  • 委托加函数:第一次用 =,之后用 obj.del = obj.del + fun。
  • Lua 没有 +=,不能直接 +,不能对事件直接 = 清空。
  • 事件通过封装的方法调用来加减(本例 obj:eventAction("+", fun) / ("-", fun))。
  • 不要往委托/事件里塞临时函数,不好移除。
