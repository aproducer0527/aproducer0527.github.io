⚠️ 在 Lua 里创建出来的字典,直接用 dic2["键"] 取值是 nil,必须用 get_Item("键") / set_Item("键", 值) 这两个固定方法。

小结

  • 数组/List/字典都是 userdata,# 取不了长度,要用 Length / Count。
  • 遍历索引按 C# 从 0 开始。
  • 创建 List/字典:先 泛型类(元素类型) 得到类型,再 类() new 对象。
  • Lua 里建的字典用 get_Item / set_Item 取值改值,不要用 []。
