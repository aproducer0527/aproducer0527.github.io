Lua 调用 C#:调用 C# 的 ref 和 out 方法

Lua 调用 C# 中带 ref / out 参数的方法时,它们的值会以多返回值的形式返回给 Lua。

C# 侧定义

Lua 侧使用

ref 参数

ref 参数必须传一个默认值占位置,真正的结果会通过多返回值拿回来。

out 参数

out 参数不需要传占位值,直接少传两个参数。

关键点

Lua 侧接收返回值的规则:

ref 和 out 的唯一区别:

  • ref:调用时必须传一个默认值占位置
  • out:可以直接省略不传

小结

  • ref / out 参数的结果通过多返回值返回给 Lua。
  • 第一个返回值是 C# 函数自己的 return,之后才是 ref/out 的结果。
  • ref 要传占位值,out 不用传。
