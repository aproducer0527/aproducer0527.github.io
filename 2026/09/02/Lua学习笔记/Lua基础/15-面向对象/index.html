15-面向对象

发表于2026-09-02|更新于2026-09-02|Lua学习笔记Lua基础
|浏览量:

面向对象

Lua 的面向对象(类)其实都是基于 table 来实现的,配合上一课讲的元表 __index。

封装(定义类 + 构造)

new 的实现逻辑:

  1. 创建一个空表 obj
  2. 让 Object 自己作为 __index(找不到属性就去 Object 里找)
  3. 把 Object 作为 obj 的元表
  4. 返回 obj,这样 new 出来的对象就能继承 Object 的属性和方法

继承

多态

子类重写父类方法(多态),重写后还想执行父类逻辑时,用 self.base.方法(self) 这种点号调用,把基类表作为第一个参数传进去,而不是用冒号。

小结

  • 类 = table + 元表(__index)。
  • new 实现构造:obj 设 Object 为元表并指定 __index = Object。
  • subClass 实现继承,子类保存 base 引用指向父类。
  • 多态 = 子类重写方法;想调用父类逻辑时用点号调用 self.base.方法(self)。
