Table 表(迭代器遍历)

迭代器主要是用来遍历表的。一般我们不用 # 得到长度,因为它并不准确。

ipairs 迭代器

ipairs 会忽视所有非 number 型的变量。

  • 从 1 开始往后遍历
  • 小于等于 0 的值得不到
  • 如果中间断开(遇到 nil)也不会继续遍历

pairs 迭代器

pairs 能把所有键都找到。

  • pairs 会先顺序输出键值对,然后再输出乱序部分的键值对(按键存储时的哈希值来决定)
  • 所以 table 后半部分输出的并不是键 -1、键 4、键 5 从小到大

小结

  • ipairs:只遍历从 1 开始连续的 number 键,遇到 nil 就停,非 number 键忽略。
  • pairs:遍历所有键值对,包括自定义键,但顺序不一定有序。
  • 遍历值不想取键时,用 _ 占位。
