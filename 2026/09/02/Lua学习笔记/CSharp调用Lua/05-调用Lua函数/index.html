C# 调用 Lua:调用 Lua 函数

C# 调用 Lua 里的函数,最常用的方式是通过委托去接,然后用调用委托的方式来调用 Lua 函数。

Lua 侧函数定义

C# 侧定义委托

[CSharpCallLua] 特性在 XLua 命名空间中,加了它之后生成代码时才会自动生成这个委托的注册代码。

C# 侧调用

关键点

无参函数

有 4 种接法,推荐用委托 / UnityAction / Action:

  • CustomCall(自定义委托)
  • UnityAction(Unity 自带)
  • Action(C# 自带)
  • LuaFunction.Call()(XLua 提供的方法,少用,效率低)

有参函数

  • Func<int, int> 可以接到带返回值的函数。
  • 同样可以用 LuaFunction.Call(参数)。

多返回值

多返回值需要用 out 或 ref 去接:

用 LuaFunction.Call() 会返回一个 object[] 数组,里面就是所有返回值。

变长参数

C# 用 params int[] args 接 Lua 的 ...,参数个数随意。

小结

  • C# 调 Lua 函数:Global.Get<委托类型>("函数名") 拿到委托,再调用。
  • 有参、多返回、变长参数的委托都要加 [CSharpCallLua]。
  • 多返回值用 out / ref 接,LuaFunction.Call() 返回 object[]。
  • LuaFunction 效率低,尽量少用。
