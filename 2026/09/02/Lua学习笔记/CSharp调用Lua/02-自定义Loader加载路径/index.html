C# 调用 Lua:自定义 Loader 加载路径

XLua 提供了路径重定向的方法,允许我们自定义加载 Lua 文件的规则。

当我们执行 lua 语言的 require 时,相当于执行一个 lua 脚本,此时就会进入我们自定义的加载函数去查找文件。

核心用法

关键点

AddLoader 注册加载函数

env.AddLoader(MyCustomLoader) 注册一个自定义加载函数。之后每次执行 require 都会调用这个函数。

加载函数的签名

  • 参数 ref string filePath:require 的脚本名(不带后缀)。
  • 返回值 byte[]:返回的是脚本的字节数组,Lua 解析器用这个数组来执行脚本。
  • 找不到文件时返回 null。

拼接路径

把脚本名拼上固定目录和后缀,得到完整的文件路径。这里的目录和后续 LuaMgr 里写的 Application.dataPath + "/Lua/" + filePath + ".lua" 要保持一致。

示例里判断”脚本后缀名错误”的代码:当脚本名本身带 .lua 后缀时(等于拼出的 .lua.txt 结果),说明使用者传了后缀,就提示错误。

小结

  • AddLoader 自定义 require 的文件查找规则。
  • 加载函数按 ref string 拿脚本名,拼出路径,返回 byte[] 字节数组。
  • 找不到文件返回 null,并且做好提示。
