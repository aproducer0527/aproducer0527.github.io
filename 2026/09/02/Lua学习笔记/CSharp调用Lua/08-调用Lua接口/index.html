C# 调用 Lua:调用 Lua 接口

除了用类去接 Lua 表,还可以用接口去接。接口同样要加 [CSharpCallLua] 特性,使用规则和类一样。

和类最大的区别:接口是引用拷贝,改 C# 侧的值会直接改到 Lua 表里!

关键点

接口 + [CSharpCallLua]

接口必须要加 [CSharpCallLua] 特性,才会生成对应的注册代码。**注意此处的 testBool、testFloat 声明成了 int**——接口属性类型需要和 Lua 里的值对应上,写代码时注意别搞错(实际项目里应保持一致类型)。

接口没有字段,用属性

类可以用 public int testInt; 字段,接口里要用属性 int testInt { get; set; }。

嵌套接口

Lua 的嵌套表 SonClass 用嵌套接口 ICSharpCallSonInterface 来接。

引用拷贝(和类的最大区别)

类和接口都能接同一个 Lua 表 testClass,但:

  • 类 = 值拷贝:改 C# 侧不影响 Lua 表。
  • 接口 = 引用拷贝:obj.testInt = 10000 会直接修改 Lua 表里的 testInt。

这是接口方案的优势,可以双向修改。

小结

  • 接口接 Lua 表:属性名和 Lua 键名一致,加 [CSharpCallLua]。
  • 接口用属性、嵌套接口接嵌套表。
  • 接口是引用拷贝,修改会同步回 Lua 表;类是值拷贝。
