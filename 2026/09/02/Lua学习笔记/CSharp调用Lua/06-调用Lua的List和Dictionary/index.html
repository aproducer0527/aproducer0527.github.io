C# 调用 Lua:调用 Lua 的 List 和 Dictionary

Lua 的 table 可以当成 List(数组)或 Dictionary(字典)来用,C# 侧可以把它读成对应的 C# 容器类型。

关键点

读成 List

  • List<int> 读纯数字数组。
  • List<object> 读元素类型不统一的数组(字符串、布尔、数字混着)。

读成 Dictionary

  • Dictionary<string, int> 读键值都是常见类型的字典。
  • Dictionary<object, object> 读键值类型不统一的字典(Lua 里 [true]、[false] 这种都能当键)。

值拷贝

这里拿到的 List / Dictionary 都是值拷贝,在 C# 里增删改不会改变 Lua 中的内容。

如果需要修改 Lua 里的内容,得用别的方式(比如操作 LuaTable)。

小结

  • Global.Get<List<T>>("表名") 把 Lua 数组读成 C# List。
  • Global.Get<Dictionary<K,V>>("表名") 把 Lua 字典读成 C# Dictionary。
  • 类型不统一时用 object。
  • 读出来的都是值拷贝,改了不影响 Lua 原表。
